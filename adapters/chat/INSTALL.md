# SpineMe in any chat app

Extract `spineme-chat.zip`. Attach `SKILL.md` if the app supports files, or paste
its contents. Supply the code, logs, and prior findings to review, then send:

```text
Follow the SpineMe instructions I provided.
Review only the supplied material. Use compact output.
State your evidence scope, missing access, and checks you cannot run.
Recommend model capabilities only when needed; do not invent available models.
```

This is a prompt adapter, not an installed plugin. Repeat in a new chat unless
your app retains the instructions through a supported project/custom-instruction
feature. No chat app is assumed to have filesystem or test execution access.
