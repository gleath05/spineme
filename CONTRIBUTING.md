# Contributing

Edit `skills/spineme/SKILL.md` for audit behavior and `adapters/` for host setup.
Do not hand-edit the generated ZIPs in `dist/`.

Run `python3 scripts/build.py` followed by `python3 scripts/check.py`.
Use Python 3.8 or later; no third-party build dependencies are needed.

Preserve read-only audits, evidence-based confidence, scoped-readiness limits,
stable finding IDs, and vendor-neutral model guidance. Report the host/version,
model, relevant fixture, and observed result when proposing a compatibility change.
Never include credentials or private repository content in examples or issues.

Licensing is pending the owner's choice; no open-source license has been assigned.
